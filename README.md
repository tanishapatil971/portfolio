# Tanisha Patil — Portfolio Website

Personal portfolio website of Tanisha Patil, Web Developer & Computer Science (AIML) Student.

## Features

- **Projects Showcase**: Highlighting key projects like StartupOS and Muhurta Yatra.
- **Experience & Education**: Timeline of work experience and academic milestones.
- **Skills & Credentials**: Categorized skill matrix and verified certifications.
- **Contact & Communications**: Direct email integration and social links.

## Development Setup

```sh
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- React 19 & TypeScript
- TanStack Start & Router
- Tailwind CSS
- Lucide Icons
